See everything Claude is doing. Live.

A mod for Claude Code

Mission Control is a mod for Claude Code, in the desktop app and the CLI. It shows who is working, on what, how far along, and what it costs, while Claude works.

The problem

Claude works in steps, tools and sub-agents. Most of it scrolls past unseen.

Who is working?

Sub-agents start and finish out of sight.

How far along?

The plan lives in the chat, not on screen.

What does it cost?

Tokens and limits only show up when you ask.

The three questions everyone asks while Claude runs a long job. Mission Control answers all three at a glance, without asking Claude.

What it shows

A HUD band and a live pane

  • Band above the prompt: the boss, the task, a progress gauge
  • Readouts: context, 5-hour limit, burn rate, tok/s, cost
  • Steps: the plan as pips, live
  • Done chime and a stuck alarm after 2 quiet minutes
Left: the full pane. The band sits above the prompt and is always on. Open the pane with /missioncontrol. Live in the demo: start a task and watch the band and steps move.

The crew

Every sub-agent, by role, under the manager

Crew mode splits big jobs across sub-agents on its own. Finished agents fold away.

Each role gets a colour and a figure. Big jobs (a long brief, many files, a codebase sweep, a long plan, or a full context) are split across sub-agents automatically; /autocrew turns it on or off.

Token Manager

Watches every token, so you don’t have to

Cost per task

Burn rate, cache hits and spend, in 6 currencies.

Budget warnings

Set a per-task budget; it warns at 80% and 100%.

Haiku autopilot

Read-only explorers run on Haiku unless you pick a model.

Cache countdown

A toast at 10 and 5 minutes before the prompt cache expires.

All of this runs locally in the mod; it reads the session's usage and the requests Claude makes. /tokens gives a text report, /tokens budget 2 sets a 2-dollar budget per task, /tokens autopilot on turns on the Haiku autopilot.

Pick with /skins, or make your own as a small JSON file.

Each skin restyles the band, the pane, the chat’s tool rows and the spinner. Custom skins go in a “Custom Claude Skins” folder; /skin reload picks up edits.

The add-on swaps the crabs for a pixel-art cast and adds a progression system. It is a fan homage, not affiliated with CD PROJEKT RED, Studio Trigger or Netflix.

Install in 3 steps

  1. Clone the repo, or download a zip
  2. Add the folder to CLAUDE_CODE_PLUGIN_DIRS in ~/.claude/settings.json
  3. Restart Claude Code

Works on macOS, Windows and Linux, in the desktop app and the CLI.

Commands

CommandWhat it does
/missioncontrolOpen the pane
/skinsPick a skin
/tokensToken report and budget
/autocrewCrew mode on or off
/prefsHow Claude should answer
On macOS several mod folders are separated with a colon in CLAUDE_CODE_PLUGIN_DIRS; on Windows with a semicolon. CLAUDE_CODE_PLUGIN_DIR_WATCH=1 reloads the mod when its files change.
