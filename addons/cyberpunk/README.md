# Cyberpunk Skins add-on

Unlocks **Cyberpunk 2077**, **Lucy · Edgerunners** and **Arasaka** (and one secret), with the pixel-art cast, Street Cred, Braindance, the boot line and the sound pack in `assets/`. `skins/` holds the three skins as JSON, to copy as a starting point for your own.

Install: put this `cyberpunk` folder at `addons/cyberpunk/` inside your Mission Control folder, then run `/skin reload` (or restart) and `/skins`.
